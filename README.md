# BOOKESH

Smart Movie, Event & In-Seat Food Booking Platform
Bookesh is a full-stack web application that integrates movie ticket booking, event discovery, personalized recommendations, and in-seat food ordering into a single platform, designed to enhance the overall entertainment experience.

---------------------------
# FEATURES

Movie & Event Booking
Browse, select, and book tickets for movies and events
Authentication & User Management
Secure login/signup system with session handling
Personalized Recommendation System
Suggests movies and events based on user preferences and activity
In-Seat Food Ordering
Order food from external restaurant providers directly to your seat
Database Integration
Efficient data handling using MongoDB for users, bookings, and preferences
Full-Stack Architecture
Backend APIs built using Node.js and Express.js to handle requests, authentication, and data flow


---------------------------
# TECH STACK

Frontend: HTML, CSS, JavaScript
Backend: Node.js, Express.js
Database: MongoDB
Version Control: Git, GitHub

-----------------------
# INSTALLATION & SETUP

# Clone the repository
git clone https://github.com/your-username/bookesh.git

# Navigate into the project
cd bookesh

# Install dependencies
npm install

# Run the application
npm start

-----------------------------
# SYSTEM OVERVIEW

The frontend handles user interaction and interface rendering.
The backend, built with Node.js and Express.js, manages APIs, authentication, and business logic.
MongoDB is used for storing user data, bookings, and preferences.
The recommendation system processes user behavior to suggest relevant movies and events.
